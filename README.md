# OpenMX H₂ — GGA-PBE

Kết quả phép tính phân tử H₂ tại khoảng cách 0,74 Å. Năng lượng tổng: −1,163792535108 Hartree; SCF hội tụ sau 14 vòng. Tệp ZIP chứa toàn bộ đầu vào, đầu ra, dữ liệu lưới và restart.

Để chạy lại trên máy khác, sửa `DATA.PATH` trong `H2.dat` cho phù hợp với nơi cài `DFT_DATA19`. Gói kết quả không bao gồm phần mềm OpenMX hoặc toàn bộ DFT_DATA19.
